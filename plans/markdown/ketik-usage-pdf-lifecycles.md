# KETIK usage display and PDF lifecycles

## Requirement

Finish the two specifically identified supporting async flows at baseline `6764b354`: replace `sessionDelta`/`sessionDeltaPending` and `downloadingPdf` with explicit status unions and centralized reducer transitions. Conservative Lane D because this touches AI-usage presentation; actual billing, logging, ledger, pricing, API, authorization and PDF contents must remain unchanged. Work directly, no delegation.

Acceptance: starting chat never waits for usage; each baseline/result belongs to one account and started session; late usage results cannot overwrite a newer session; unavailable usage is not zero/success; PDF eligibility and existing downloads/errors remain unchanged, duplicate clicks cannot start another generation, and leaving/replacing a review suppresses late download/error effects.

## Design

- Module-local usage hook/reducer owns idle/capturing/tracking/polling/ready/unavailable states, baseline, delta and operation identity. Retain `fetchUsageSummary` and `pollUsageDelta` unchanged. Begin capture asynchronously before start, bind to the returned session ID, invalidate on new start/account/unmount or opening another history session. Keep the last result when returning to the landing. A later review computation can supersede the finish computation without stale completion resetting its state.
- PDF hook/reducer owns idle/generating/completed/failed with request fencing and explicit retry. Preserve the lazy imports, real generator and downloader. Invalidate on session/review/eligibility/account change and unmount; check ownership before generation, download and toast.
- Synchronous reducer mirrors are only for reentrant async guards, following the existing KETIK reducers. No separate busy flags or new generic task framework.
- Owned paths: KETIK index, review stage, the two local hooks, focused browser specs, plan, architecture note and changelog. No shared usage math/helper, shared popover, PDF renderer, dependencies, backend, schema, remote services or legacy unit suites changed.
- Existing monthly-summary delta is an estimate, not a server-attributed session ledger. This task preserves that limitation, and prevents stale display attribution rather than changing the accounting contract.
