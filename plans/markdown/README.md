# Per-feature plans

Lane C/D persisted plans for this repository live here and are tracked in Git.

- Naming: `<feature>.md` (kebab-case, one feature per file).
- Required sections: **Requirement**, **Design**, **Tasklist** (see [`docs/AGENT_WORKFLOW.md`](../../docs/AGENT_WORKFLOW.md) §3).
- The improvement-plan execution index is [`plans/README.md`](../README.md); this directory does not duplicate its status table.
- The git-ignored `plan/markdown/` directory is a legacy local archive. Do not add new plans there.
